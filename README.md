# AVTagEditor
Supported formats: MP3, AAC, M4A, OGG, WMA, WAV, AIFF, FLAC, MKA, DSF, WV, OGA, MP4, MKV, WMV, AVI, ASF, WEBM, MPEG, OGV, OPUS  
Supported platform: Windows 10, 11  
UI Language: English, Czech, Chinese, Finnish, French, German, Hindi, Italian, Japanese, Korean, Portuguese, Romanian, Russian, Spanish  
Batch tag editing (Edit multiple file tags at once)  
Batch file renaming  
Batch Cover Art editing  
Automatic lyric downloads  
Automatic downloads of album cover art and movie or TV cover art  
Automatic album-information downloads  
Automatic subtitle downloads for movies and TV series  
Saving, removing, and assigning cover art and lyrics  
Displaying file information  
Saving playlists in M3U formats  
Saving lyrics in ODT, DOC, DOCX, PDF, RTF, HTML, TXT formats  
Built-in media player  
Bookmarks    
Lookup in Browser
